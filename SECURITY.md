# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Yes |
| < 1.0   | ❌ No |

## Reporting a Vulnerability

**DO NOT use GitHub issues.** Email security reports to:

**peakui@proton.me**

Please include:
- Description of the vulnerability
- Steps to reproduce
- Affected version

### What to expect:
- **48 hours** - Acknowledgment
- **7 days** - Assessment
- **14 days** - Fix
- **30 days** - Public disclosure

## Built-in Security

- CSS value sanitization
- Selector escaping (`CSS.escape()`)
- Prototype pollution prevention
- Color validation

## Best Practices

- Always use the latest version
- Don't pass user input to class names
- Review custom extensions before adding
